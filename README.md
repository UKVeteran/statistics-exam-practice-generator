# Statistics Exam Practice Generator

An interactive web application built with Streamlit that generates dynamic statistics problems, automated answer checking, progressive hints, and a PDF worksheet generator for educators.

## Features
- **Configurable Difficulty:** Easy, Intermediate, and Advanced tiers.
- **Dynamic Problem Types:** Summary statistics, histogram interpretation, box plot quartile analysis, normal distribution probabilities, and one-sample $t$-tests.
- **Interactive Practice:** Instant feedback, hints, and fully worked-out solutions.
- **Teacher Mode:** Export custom practice packets and answer keys into professional PDFs via ReportLab.

## Installation & Running Locally

1. Clone the repository and navigate to the project folder.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run unit tests:
   ```bash
   pytest -v
   ```
4. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```
